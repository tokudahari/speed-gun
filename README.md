# speed-gun — 球速メーター

iPhoneのスロー動画（240fps）をコマ送りし、スタートとゴールの2コマの間の時間と距離から球速（km/h）を出す1ファイルのWebページ。

- 本体: `index.html`（HTML/CSS/JavaScriptを1ファイルにまとめたもの。外部のライブラリは使っていない）
- 経緯と仕様: Google ドライブ「Claude引き継ぎ」の `2026-11-22_球速測定Webアプリ作成（アプリのチャットから）`

## 計算

- 時間（秒）＝ コマ数 ÷ 撮影fps
- 球速（km/h）＝ 距離（m）÷ 時間 × 3.6

## 「撮影fps」と「ファイルのコマ間隔」を分けている理由

写真ライブラリから渡されたスロー動画は、240コマを30コマ/秒で再生する動画に引き伸ばされていることがある。
ファイルの中のコマを1枚ずつ数え、1コマ＝実際の1/240秒として計算すれば、どちらの形でも時間は同じになる。
ページを開くと、少しだけ再生してファイルのコマ間隔を自動で調べる（requestVideoFrameCallback を使用）。

## 確認済み（2026-11-22、Mac の Chrome）

- 240fpsの動画と、30fpsに引き伸ばした動画の両方で、コマ間隔の自動判定・コマ送り・コマ戻しが正しく動く（表示のコマ番号と映像のコマが一致）
- 3m・36コマ・240fps → 72.0 km/h
- iPhoneの幅（390px）で横にはみ出さない
